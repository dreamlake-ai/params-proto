# Environment & fields

Read typed environment values and define computed fields. `EnvVar` is a public callable singleton, not a class you need to import from an implementation module.

```python
from params_proto import proto, EnvVar, Field

@proto
class Config:
    port: int = EnvVar @ "PORT" | 8080
```

Environment values resolve lazily when accessed. See the [environment guide](/key_concepts/environment_variables) for template expansion and defaults. `parse_env_template` and `all_available` are lower-level template helpers.

<a id="params_proto.envvar--envvar" />

### `EnvVar`

```python
EnvVar = _EnvVar()
```

[Source](https://github.com/dreamlake-ai/params-proto/blob/v3.3.0/src/params_proto/envvar.py#L230)

Environment variable reader that supports three syntaxes:

1. Matmul operator with env var name:
    batch_size: int = EnvVar @ "BATCH_SIZE"

2. Matmul operator with pipe for default:
    learning_rate: float = EnvVar @ "LR" | 0.001

3. Function call syntax:
    db_url: str = EnvVar("DATABASE_URL", default="localhost")
    data_dir: str = EnvVar("$DATA_DIR/models", default="/tmp/models")

4. OR operation with multiple env var names (tries each in order):
    api_key: str = EnvVar @ "API_KEY" @ "SECRET_KEY" | "default"
    # Or function syntax:
    api_key: str = EnvVar("API_KEY", "SECRET_KEY", default="default")

The pipe operator (|) allows clean chaining of env var name with fallback value.
Values are loaded lazily - environment variables are read at access time, not definition time.

#### `EnvVar.__matmul__`

```python
def __matmul__(self, other: Any)
```

[Source](https://github.com/dreamlake-ai/params-proto/blob/v3.3.0/src/params_proto/envvar.py#L61)

Support EnvVar @ "VAR_NAME" syntax, chainable for OR operation.

**Examples**

```python
EnvVar @ "VAR_NAME"              # Single env var
EnvVar @ "VAR1" @ "VAR2"         # OR: try VAR1, then VAR2
EnvVar @ "VAR1" @ "VAR2" | default  # With fallback
```

Note: The | operator has lower precedence than @, so
`EnvVar @ "A" @ "B" | default` is parsed as `(EnvVar @ "A" @ "B") | default`.

**Args**

- `other`: Either an environment variable name (str) or a default value

**Returns**

New _EnvVar instance configured with the given parameter

<a id="params_proto.envvar--envvar.__or__" />

#### `EnvVar.__or__`

```python
def __or__(self, other: Any)
```

[Source](https://github.com/dreamlake-ai/params-proto/blob/v3.3.0/src/params_proto/envvar.py#L86)

Support chaining with | to specify default value.

Syntax: EnvVar @ "VAR_NAME" | default_value

Note: Using `or` instead of `|` will NOT work because `or` has lower
precedence than @ and evaluates truthiness instead of calling __or__.

**Args**

- `other`: Default value to use if env var is not set

**Returns**

New _EnvVar instance with both template(s) and default

Support EnvVar("VAR_NAME", ..., default=...) function call syntax.

**Examples**

```python

```

**Args**

- `*templates`: One or more environment variable names or template strings
- `default`: Default value if no environment variable is set
- `dtype`: Optional type to convert the value to

**Returns**

New _EnvVar instance configured with the given parameters

## params_proto.parse_env_template

<a id="params_proto.parse_env_template--parse_env_template" />

### `parse_env_template`

```python
def parse_env_template(template: str) -> List[str]
```

[Source](https://github.com/dreamlake-ai/params-proto/blob/v3.3.0/src/params_proto/parse_env_template.py#L5)

Extract and return the environment variable names from a given string template.

:param template: A string template that potentially contains environment variables
                 in the format $VAR_NAME, $&#123;VAR_NAME&#125;, or similar.
:return: A list of environment variable names found in the template.

<a id="params_proto.parse_env_template--all_available" />

### `all_available`

```python
def all_available(template: str, strict=True) -> bool
```

[Source](https://github.com/dreamlake-ai/params-proto/blob/v3.3.0/src/params_proto/parse_env_template.py#L19)

Check if all environment variables in the template are available in the current environment.

:param template: A string template that potentially contains environment variables
                 in the format $VAR_NAME, $&#123;VAR_NAME&#125;, or similar.
:param strict: If True, treat empty environment variables as undefined. Otherwise, treat them as defined.
:return: True if all environment variables are available, False otherwise.
